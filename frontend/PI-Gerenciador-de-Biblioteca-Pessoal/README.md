# 💻 Frontend - Gerenciador de Biblioteca Pessoal

Este é o cliente web do sistema de Gerenciador de Biblioteca Pessoal, desenvolvido com Angular.

## 🚀 Tecnologias
- **Angular 21**
- **TypeScript**
- **RxJS**
- **Vitest** (Testes)
- **Prettier** (Linting)

## 📦 Pré-requisitos
- Node.js v20+
- npm v10+

## 🛠️ Configuração e Execução

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Inicie o servidor de desenvolvimento:
   ```bash
   npm start
   ```

O site estará disponível em `http://localhost:4200`.

## 🧪 Testes
Para executar os testes unitários com Vitest:
```bash
npm test
```

Para verificar a cobertura de testes:
```bash
npm run test:coverage
```

## 🎨 Padronização de Código
O projeto utiliza Prettier para manter a consistência do código. Para formatar os arquivos:
```bash
npx prettier --write .
```

## 🏗️ Estrutura de Pastas
- `src/app/components`: Componentes reutilizáveis da interface.
- `src/app/services`: Serviços para comunicação com a API.
- `src/app/models`: Definições de interfaces e tipos.
- `public/`: Assets estáticos (imagens, ícones).
